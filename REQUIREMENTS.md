# Submission requirements — checked 8 November 2026

[Official rules](https://learn-specs.devpost.com/rules) · [Competition page](https://learn-specs.devpost.com/) · [FAQ](https://learn-specs.devpost.com/details/faqs)

The project must be a new SPECS Lens planned with the Devpost Learn skill pack and built through CLAD, Lens Studio and Lens Studio MCP. It must install and run consistently in Lens Studio Preview, matching its description and demonstration. Judging requires a public repository with the project, English submission materials and a public YouTube demonstration shorter than three minutes. Pre-existing work and third-party components must be disclosed and used under their applicable terms.

The deadline is **9 November 2026, 17:00 EST (23:00 Europe/Madrid)**. The working project must remain available for judging through **17 November 2026**. The organizer controls eligibility and judging; a submitted status is not an eligibility ruling.
