# Build and verification record

Andrei Mikhailov brought a background in plant genetics, practical PCR laboratory experience and software development to the learning question. His goal is to make biological cause and effect understandable through model experiments for people without access to a physical laboratory. He selected the published evidence, defined scientific boundaries, directed the visual design and AI-assisted development, and refined the lesson through Preview testing and first-time viewer feedback.

The Devpost Learn plan-lens materials informed the design. The owner chose the learning question, evidence, visual direction and intervention. The original planning process used the guidance and brief template; it did not include every question in the standard learner interview.

R35 integrates the approved lesson into the native SPECS project. Work includes the nine-chapter Explore and guided routes, published and constructed geometry, English in-scene teaching text, source cards, native interaction controls and separate caption tracks. The active Lens Studio 5.23.2 project was opened, authorized, compiled, bound and saved through Lens Studio MCP tools via the official Codex App Server. The inspector and the Lens JS debugger were used to observe Preview. SIK pinches were exercised in Preview.

The virtual laboratory and earlier botanical material are credited in THIRD_PARTY_NOTICES.md. The source folder lists the independent microscopy specimen, the modeled GL1 DNA, cryo-EM coordinates and predicted reference protein separately. Reproduction instructions cover the simulator. Physical SPECS were not used.

The initial prototype began in an existing Lens Studio template configured for SPECS. The Devpost Learn design references and template were revisited for R35. The brief identifies the spatial moment, station placement, hand input, model boundaries and criteria that can be checked in Preview. [Devpost Learn skill pack](https://github.com/challengepost/learn-specs). [Official competition rules](https://learn-specs.devpost.com/rules).
